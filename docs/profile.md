# Profile Notes

## Stats

The README expects a self-hosted Vercel instance for GitHub stats.

Replace `YOUR_VERCEL_URL` in [README.md](../README.md) with your deployed base URL.

Current profile URLs are tuned for:

- GitHub stats
- Top languages
- Streak

## Snake

The snake animation is generated by [.github/workflows/snake.yml](../.github/workflows/snake.yml).

It publishes the generated SVGs to the `output` branch and uses the project palette.
